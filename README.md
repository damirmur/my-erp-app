# Low-Code ERP Constructor

Конструктор учётных систем в стиле 1С:Предприятие. Метаданные и данные хранятся локально в IndexedDB и синхронизируются с Supabase.

---

## Quick Start

```bash
npm install
npm run dev
```

Dev server: `http://10.66.66.9:5173`

```bash
npm run build    # production build
npm run check    # type-check
npm run format   # auto-format (Prettier)
```

## Как это работает

### Боковая панель (слева)

- Все созданные таблицы сгруппированы по типам: **Справочники**, **Документы**, **Регистры**, **Системные**
- Клик по таблице открывает её список (или форму, если запись уже выбрана)
- Кнопка **🔧 Конфигуратор** открывает конструктор метаданных

### Рабочая область

Табы: список записей + форма редактирования. Можно открыть несколько объектов одновременно.

### Конфигуратор

Две колонки:

**Левая панель**
- **➕ Новая таблица** — создать справочник или документ
- **⚙️ Типы таблиц** — управление типами (создать, удалить; встроенные directory/document/template защищены от удаления). Новый тип создаётся на основе существующего — копирует его статусы, фичи и действия.

**Правая панель** (после выбора таблицы)
- **Реквизиты шапки** — добавлять/редактировать/удалять колонки (имя, заголовок, тип)
- **Настройки объекта** — флаги возможностей (иерархия, копирование, печать, табличные части) + переопределение read-only по статусам
- **Табличные части** — создание подчинённых таблиц с собственными реквизитами

### Создание таблицы

1. В Конфигураторе введите название и выберите тип
2. После создания откройте таблицу в правой панели
3. Добавьте реквизиты (строки, числа, даты, булево, ссылки)
4. Сохраните настройки
5. Закройте Конфигуратор — таблица появится в боковой панели

### Работа с записями

- **Список**: сортировка по колонкам, массовые операции (пометить на удаление, восстановить, провести)
- **Форма**: заполнение полей, проводка/отмена, печать
- **Иерархия** (для справочников): группы/папки, двойной клик для входа в папку

### Синхронизация

- Автоматически каждые 60 секунд (если есть интернет)
- При запуске приложения
- После любых изменений в Конфигураторе
- Офлайн-режим: данные сохраняются локально, синхронизация отложится

## Типы таблиц (встроенные)

| Тип | Описание | Статусы | Возможности |
|-----|----------|---------|-------------|
| Справочник | Папки/группы с иерархией | Записан, Помечен на удаление | Иерархия, копирование, печать, ТЧ |
| Документ | Проводящиеся документы | Черновик, Проведен, Помечен на удаление | Копирование, печать, ТЧ |

### Как добавить новый тип

В Конфигураторе → **Типы таблиц** → **Новый тип**. Укажите имя (лат.), метку и базовый тип для копирования структуры. Новый тип сразу станет доступен при создании таблиц.

## Типы реквизитов

| Тип | Вид в форме |
|-----|-------------|
| Строка | `<input type="text">` |
| Число | `<input type="number">` |
| Булево | `<input type="checkbox">` |
| Дата | `<input type="date">` |
| Ссылка | Поисковый автокомплит по связанному справочнику |

## Печать

Для таблицы можно создать печатную форму — HTML-шаблон с переменными `{{doc.title}}`, `{{#each lines}}...{{/each}}`.

## Технологии

- **Frontend**: Svelte 5 (runes), SvelteKit 2, TypeScript
- **Хранилище**: Dexie.js (IndexedDB) — офлайн, Supabase (PostgreSQL) — облако
- **Форматирование**: Prettier (табы, одинарные кавычки)
